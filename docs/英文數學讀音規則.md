# 英文數學讀音規則(錄前判讀依據)

適用範圍:國小到國中數學英文課程的所有預錄旁白(閱讀、動畫段落、題庫、遊戲)。
狀態:**規則草案,尚未經確認,尚未用於錄音。**

## 0. 基本設定

| 項目 | 設定 | 狀態 |
|---|---|---|
| 口音與用字 | 美式英語(General American) | 已確認(2026-11-12) |
| 0 的讀法 | zero(不用 oh、nought) | 固定 |
| 整數讀法 | 不加 and:125 → one hundred twenty-five | 固定(美式) |
| 等號 | equals(全課程不混用 is equal to) | 固定 |
| 負數 | negative(不用 minus) | 固定(美式) |
| 四分之幾 | fourth / fourths(quarter 只用在時間與錢幣) | 固定(美式) |

## 1. 判讀流程

每一句錄音前,把「顯示文字」轉成「朗讀文字」,語音引擎只讀朗讀文字。

1. 找出句中所有符號、數字、縮寫、單一字母、英文多音字。
2. 每一項依下列順序處理:
   - 第 2 節有對應 → 直接套用,列為**固定**。
   - 第 3 節有對應 → 依句意判斷,列為**已判斷**並寫出依據。
   - 第 4 節的多音字 → 依詞性與句意判斷,列為**已判斷**。
   - 符合第 5 節任一條件 → 列為**待確認**,不錄音,等使用者決定。
3. 朗讀文字只改讀法,不改句意、不增刪教學內容。
4. 同一個算式在同一單元內讀法必須一致;已確認的判斷寫入覆寫紀錄,之後相同句子直接沿用。

## 2. 固定規則

### 2.1 運算與關係

| 符號 | 朗讀文字 | 例 |
|---|---|---|
| + | plus | 3 + 4 → three plus four |
| −(兩數之間) | minus | 9 − 5 → nine minus five |
| × | times | 6 × 7 → six times seven |
| ÷ | divided by | 8 ÷ 2 → eight divided by two |
| = | equals | 3 + 4 = 7 → three plus four equals seven |
| ≠ | is not equal to | |
| < | is less than | |
| > | is greater than | |
| ≤ | is less than or equal to | |
| ≥ | is greater than or equal to | |
| ≈ | is approximately equal to | |
| ± | plus or minus | |
| 餘數 | remainder | 17 ÷ 5 = 3 … 2 → seventeen divided by five equals three remainder two |
| % | percent | 25% → twenty-five percent |
| \|x\| | the absolute value of x | |
| π | pi | |

### 2.2 整數

- 逐位值讀出,不加 and:3,406 → three thousand four hundred six。
- 21 到 99 用連字號:forty-two。
- 序數:1st first、2nd second、3rd third、4th fourth。
- 逗號千分位不讀出。

### 2.3 分數

| 情況 | 規則 | 例 |
|---|---|---|
| 分母 2 | half / halves | 1/2 → one half;3/2 → three halves |
| 分母 3 到 20 | 分子基數 + 分母序數,分子大於 1 時加 s | 2/5 → two fifths;3/4 → three fourths |
| 分母大於 20、含變數、含算式 | over | 17/100 → seventeen over one hundred;a/b → A over B |
| 帶分數 | 整數 + and + 分數 | 2⅓ → two and one third |
| 分子或分母是算式 | the fraction … over … | (x+1)/2 → the fraction x plus one, over two |

### 2.4 小數

- 小數點讀 point,小數點後逐位讀:3.14 → three point one four。
- 整數部分是 0 要讀出:0.05 → zero point zero five。
- 小數點前照整數讀:12.5 → twelve point five。

### 2.5 次方與根號

| 符號 | 朗讀文字 |
|---|---|
| x² | x squared |
| x³ | x cubed |
| x⁴ 以上 | x to the fourth power(序數 + power) |
| xⁿ | x to the power of n |
| 10⁻² | ten to the power of negative two |
| (x+1)² | the quantity x plus one, squared |
| 3 × 10⁵ | three times ten to the fifth power |
| √x | the square root of x |
| ∛x | the cube root of x |

### 2.6 代數

- 字母一律讀字母名稱。**單獨的變數 a 在朗讀文字寫成大寫 A**,避免被讀成冠詞。
- 係數與變數相乘不讀 times:2x → two x;3xy → three x y;ab → A B。
- 下標:x₁ → x sub one;aₙ → A sub n。
- 函數:f(x) → f of x。
- 座標:(3, −2) → the point three, negative two。
- 機率:P(A) → the probability of A。

### 2.7 幾何

| 符號 | 朗讀文字 |
|---|---|
| ∠ABC | angle A B C |
| △ABC | triangle A B C |
| 線段 AB(上有橫線) | segment A B |
| 直線 AB(雙箭頭) | line A B |
| 射線 AB | ray A B |
| ∥ | is parallel to |
| ⊥ | is perpendicular to |
| ≅ | is congruent to |
| ∼(幾何) | is similar to |
| 90° | ninety degrees |

### 2.8 單位

- 縮寫一律展開:cm → centimeters、kg → kilograms、mL → milliliters、km/h → kilometers per hour。
- 數值是 1 用單數,其他(含 0、小數)用複數:1 meter、0.5 meters、0 meters。
- 面積與體積:cm² → square centimeters;m³ → cubic meters。
- 溫度:25°C → twenty-five degrees Celsius。

### 2.9 其他

- 英文縮寫讀字母:LCM → L C M;GCF → G C F。
- 引號裡的數字單字照畫面讀,不加字:"three" is written 3. → Three is written three.(已確認 2026-11-13)
- 用字照顯示文字讀,不替換成美式用字:sweets、tick、maths 維持原字,只用美式發音。(已確認 2026-11-13)

### 2.10 圖示(emoji、小圖)(已確認 2026-11-13)

由判讀者辨認圖示是什麼,轉成英文字讀出來。

| 情況 | 規則 | 例 |
|---|---|---|
| 圖示在句子裡當作一個詞 | 讀出名稱,單複數依數量和文法 | Each bunny gets one 🍎. How many 🍎 do you need? → Each bunny gets one apple. How many apples do you need? |
| 多個相同圖示在句子裡 | 讀成 these + 複數名稱,不讀出個數 | Which is the same amount as 🍓🍓🍓? → … as these strawberries? |
| 圖示是要學生去數的圖(在句尾或獨立成圖) | 不讀,避免直接說出答案 | How many chicks? 🐥🐥🐥🐥 → How many chicks? |
| 裝飾用圖示(按鈕、標題前的圖) | 不讀 | 🎮 Play the game → Play the game |

名稱對照:動物用頁面內建的英文名(kitten、puppy、bunny、bear、panda、chick、frog、piglet、monkey、fox)。其他圖示第一次出現時在判讀檔列出名稱,之後沿用。

### 2.11 第二批符號(2026-11-13,全課程掃描後補上)

使用者指示:符號的意思由判讀者依當下情境判斷,再決定用什麼詞。下表同一個符號有多種情境時,依情境選讀法,並在判讀檔寫出依據。

**屬於數學用語的符號**

| 符號 | 情境 | 朗讀文字 | 例 |

| ∝ | 正比 | is proportional to | y ∝ x → y is proportional to x |
| θ | 角度變數 | theta | |
| sin、cos、tan | 三角函數 | sine、cosine、tangent | tan θ = ? → tangent theta equals what |
| sin²θ | 三角函數的平方 | sine squared theta | |
| [ ] | 外層括號 | 與小括號相同,讀 the quantity;教符號本身時讀 brackets | 6 × [−1 + (−4)] → six times the quantity negative one plus negative four |
| aᵐ、aⁿ | 變數指數 | a to the power of m | aᵐ × aⁿ → A to the power of m, times A to the power of n |
| aᵐ⁺ⁿ、aᵐ⁻ⁿ、aᵐˣⁿ | 指數是算式 | a to the power of m plus n / m minus n / m times n | |
| (aᵐ)ⁿ | 次方的次方 | the quantity a to the power of m, to the power of n | |
| (−2)⁴ | 負數的次方 | the quantity negative two, to the fourth power | |
| −2⁴ | 次方後取負 | the negative of two to the fourth power | |
| a : b : c | 三項連比 | a to b to c | 1 : √3 : 2 → one to the square root of three to two |
| AA、SSS、SAS、ASA | 相似與全等條件 | 逐字母讀 | AA → A A |
| 30-60-90 triangle | 特殊三角形 | thirty sixty ninety triangle(連字號不讀) | |
| 直式的橫線 ────── | 直式計算的結果線 | equals | 2.45 + 1.38 ────── 3.83 → two point four five plus one point three eight equals three point eight three |
| 上下排版的分數 | 頁面用特殊排版顯示 | 從原始碼辨認分子分母,依 2.3 讀 | |

|---|---|---|---|

| → | 運算或移動的結果 | gives | (2, 1), 3 right and 4 down → (5, −3):… gives the point five, negative three |

## 3. 需要判斷的規則

每一項都要在判讀結果寫出「選了哪一個讀法、依據是什麼」。

| 符號 | 可能讀法 | 判斷依據 |
|---|---|---|
| − 或 - | minus / negative / to / 不讀 | 兩個數或式子之間 → minus;數或括號前面、前方沒有被減數 → negative;表示範圍(1-5、1～5)→ to;單字內的連字號 → 不讀 |
| × | times / by | 運算 → times;尺寸或排列(3 × 4 的長方形、陣列)→ by |
| : | to / 時間讀法 / 停頓 | 比與比例尺(3 : 2、1 : 100)→ to;時間(3:15)→ three fifteen;句子標點 → 停頓不讀 |
| / | 分數讀法 / per / or | 兩個數 → 依 2.3 分數規則;單位之間 → per;文字之間(and/or)→ or |
| . | point / 句點 | 兩個數字之間 → point;其他 → 句點 |
| ( ) | the quantity / of / 不讀 | 括號內是算式且前後有運算 → the quantity …,結尾用逗號停頓;函數 f(x) → of;補充說明文字 → 不讀,用停頓;教括號這個符號本身 → parentheses |
| a(b + c) | 乘法或函數 | 字母在題目中定義為函數 → A of …;否則 → A times the quantity B plus C |
| □、( )、___、? | blank / what | 填空 → blank;問句(3 + 4 = ?)→ three plus four equals what |
| ° | degrees / degrees Celsius | 角度 → degrees;溫度依單位讀 |
| ∼ 或 ~ | is similar to / to / about | 幾何圖形之間 → is similar to;兩個數之間 → to;單一數字前 → about |
| 數字串 | 整數讀法 / 逐位讀 / 年份讀法 | 數量 → 整數讀法;講位值、數字卡、電話、編號 → 逐位讀;年份 → nineteen ninety-eight、two thousand twenty-six |
| 12:00、時間 | o'clock / 逐段讀 | 整點 → twelve o'clock;3:05 → three oh five(時間是 0 讀 oh 的唯一例外);3:30 → three thirty |
| 金額 | dollars and cents | $3.50 → three dollars and fifty cents;台幣 NT$ 依課文用字 |
| x 與 × | 字母或乘號 | 依前後是否為數字與運算判斷;無法確定 → 待確認 |
| 1/4、3/4 | fourth / quarter | 一般分數 → fourth;時間(quarter past)與錢幣 → quarter |
| … 或 ... | and so on / 停頓 | 數列或規律(2, 4, 6, …)→ and so on;邊數邊說的句子(1, 2, 3 … the last number is 7)→ 停頓,不加字(已確認 2026-11-13) |
| 單一字母 A、I、O | 字母名或單字 | 當作點、圖形、變數名稱 → 讀字母名,朗讀文字加引號或大寫標示;當作冠詞或代名詞 → 照單字讀 |

## 5. 一律列為待確認的情況

1. 同一個符號套用第 3 節後仍有兩種合理讀法。
2. 朗讀文字必須增刪教學用字才能聽懂(例如需要補 the quantity 以外的說明)。
3. 巢狀括號、繁分數、分子分母都是多項式等長算式,聽眾無法只靠聽分辨結構。
4. 美式與英式讀法不同,而本文件第 0 節沒有規定。
5. 專有名詞、人名、地名、台灣特有單位(台斤、坪)的英文讀法。
6. 第 4 節多音字無法從詞性判斷。
7. 本文件完全沒有涵蓋的符號(例如集合、三角函數、Σ)。
8. 句子本身的英文或數學內容疑似有誤:先回報,使用者說「由你修正」後才改寫顯示文字,並在判讀檔記錄修正前後的句子。

## 5.1 錄音範圍

所有語音都使用預錄,不退回瀏覽器語音(已確認 2026-11-13)。

- **固定句與題庫(每個題庫固定 30 題)**:整句錄製,一句一個音檔。
- **隨機句(動手做的隨機練習、遊戲)**:比照中文版,錄「句子框架」和「數字」後由頁面拼接。
- **聲音**:Azure en-US-SaraNeural,老師和學生用同一個聲音(待使用者試聽確認)。
- **上線位置**:自己的網站,音檔放在獨立的 audio 資料夾。

## 6. 判讀結果格式

每個單元一份「單元N_英文錄前判讀.md」,比照中文版分三段:

1. **待確認**:顯示文字、建議朗讀文字、兩種讀法的差異、需要使用者決定的問題。
2. **已判斷**:顯示文字、朗讀文字、依據(寫明是第 3 節或第 4 節的哪一條)。
3. **固定**:只列統計(哪一條規則用了幾句),不逐句列出。

使用者確認後的結果寫入覆寫紀錄,格式為「顯示文字 ⇥ 朗讀文字」,一句一行。
