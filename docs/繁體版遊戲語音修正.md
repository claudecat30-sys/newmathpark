# 繁體版遊戲語音檢查與修正(2026-11-13)

對象:使用者在遊樂園介面實際聽得到的句子,也就是遊戲頁(標題、玩法、故事)和遊戲進行中的句子。
適用檔案:`預錄/index.html`、`交付_課程音檔/index.html`(兩份相同),以及兩個 `audio/` 資料夾。

## 怎麼檢查

遊戲中的句子是隨機產生的,用程式列舉不準。做法是讓頁面自動試玩每個遊戲:反覆開局、點畫面上的按鈕、按結束,同時攔截頁面送去發聲的文字。

| 輪次 | 範圍 | 每個遊戲開局次數 | 收集到的句子 |
|---|---|---|---|
| 第一輪 | 440 個遊戲 | 40 | 17,730 |
| 第二輪 | 440 個遊戲 | 50 到 80 | 24,384 |

## 修正前的狀況

第一輪 17,730 句中有 **2,354 句(13%)會退回系統語音**,影響 118 個遊戲。原因:

- 數字音檔不齊:0 到 9999 之間缺了 4,827 個。
- 一萬以上的數字、中文寫的大數(例如「八百六十三萬零七百」)沒有辦法拼。
- 小數(例如「0點五九」)的小數部分被黏在後面的文字上,組合無限多。
- 頁面會把「2 個」改成「兩 個」,讓數字 2 變成文字的一部分,原本「片段 + 數字」的拼法就對不上。
- 「第 2 個」被改成「第 兩 個」,這個讀法本身就是錯的。
- 「1/2 公升」被處理成「1/兩公升」。

## 做了什麼

**1. 頁面的前處理修正 2 處**
- 分數先轉換,再處理「2 → 兩」。
- 「第 2 個」不再轉成「第 兩 個」。

**2. 頁面加入進階拼接**

原本的查找順序是:整句 → 「片段 + 數字」→ 依逗號切段。現在在最後多一步,把句子再拆細:

| 類型 | 做法 |
|---|---|
| 一萬以上的數字 | 拆成「幾萬」「幾億」幾段,每段用 0 到 9999 的數字音檔,加上「萬」「億」「零」 |
| 中文寫的數字 | 先換算成數值,再照上面的方式拼 |
| 小數 | 「點五九」這種一到兩位的小數各有音檔;更長的逐位讀 |
| 分數 | 分母、「分之」、分子各自拼 |
| 兩 | 獨立成一個音檔 |
| 引號 | 忽略 |

都拼不出來才退回系統語音。

**3. 補錄 4,993 個片段**

| 內容 | 數量 |
|---|---|
| 0 到 9999 之間原本缺的數字 | 4,827 |
| 小數片段(點X、點XY)與「兩」 | 110 |
| 文字片段(例如「今天星期三，」「果汁要」「四捨五入到千位」) | 56 |

與先前相同的聲音(zh-TW-HsiaoChenNeural),已去除前後靜音。

**4. 刪除未使用的舊音檔**

兩個 `audio/` 資料夾各刪除約 6,940 個沒有被索引用到的音檔(各約 140 MB)。刪除後資料夾內的音檔數與索引用到的音檔數完全一致(94,041 個),沒有索引指到卻不存在的檔案。

## 驗證

- 用頁面裡實際的查找程式檢查全部收集到的句子,連同先前課文、動畫、題庫的句子,共 **69,269 句,退回系統語音 0 句**。
- 在瀏覽器用頁面本身的播放流程實測 2,013 句(每個遊戲抽樣),共播放 7,932 個音檔片段,系統語音 0 次。

## 限制

- **不是窮舉**。遊戲句是隨機的,兩輪試玩沒抽到的組合仍可能缺片段。第二輪 24,384 句只多找到 4 個缺的片段,表示已接近收斂,但不能保證是零。
- **拼接的語調**。帶數字的句子是片段接起來的,數字前後會有輕微的接縫;一萬以上的數字接縫更多。
- **音檔沒有人工試聽**。
- **自動試玩的點法有限**。它只會點按鈕和卡片,拖曳類或畫布類的互動可能沒觸發到後續的發聲。
- 能力分析、競賽頁面沒有檢查(目前這些頁面沒有發聲)。

## 還沒處理

`預錄/audio_trim`(44,941 個檔,640 MB)和 `預錄/audio_trim2`(93,484 個檔,1.36 GB)是先前去靜音時的暫存資料夾,沒有任何頁面引用。數量很大,等使用者確認後再刪。
