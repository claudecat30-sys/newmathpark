# 繁體交付版缺音檔全面掃描(2026-11-13)

對象:`交付_課程音檔/index.html` 與 `audio/index.js`(索引 89,252 筆)。
狀態:**已全部修正(2026-11-13),見文末「修正結果」。** 以下前半是修正前的掃描結果。

## 做法

把每個單元的固定文字,依頁面實際的播放方式送進頁面自己的查找流程,並攔截系統語音。音檔不實際播放。

| 模式 | 送進去的文字 | 句數 |
|---|---|---|
| 題目、解說、提示、重點、說明、標題(按 🔊) | 整段 | 17,268 |
| 動畫 | 依頁面切段 | 2,505 |
| 閱讀「全部朗讀」的段落 | 依頁面切段 | 1,870 |
| 閱讀「全部朗讀」的想一想題目 | 「想一想:」+ 題目,依頁面切段 | 6,225 |
| 合計 | | 27,868 |

**沒有涵蓋**:遊戲和動手做在執行時隨機產生的句子、選項按鈕文字、答對答錯的回饋語。

## 結果

27,868 句中有 **5,899 句(21%)** 至少有一段退回系統語音。

| 模式 | 有缺漏的句數 | 佔該模式 |
|---|---|---|
| 閱讀的想一想題目 | 3,004 | 48% |
| 題目 | 1,578 | 31% |
| 解說 | 820 | 17% |
| 閱讀段落 | 226 | 12% |
| 提示 | 105 | 8% |
| 動畫 | 62 | 2% |
| 其他(說明、重點、標題等) | 104 | 少量 |

不重複的缺漏片段共 5,835 個。各冊分布平均(一到九年級每冊約 200 到 490 句),不是集中在某幾個單元。

## 原因與處理方式

| 原因 | 片段數 | 處理方式 | 需要錄音 |
|---|---|---|---|
| 頁面把「2 個」改成「兩 個」後才查音檔,但索引裡是「2 個」 | 325 | 補索引對應 | 否 |
| 閱讀模式把「想一想:」和題目黏在一起查,查不到 | 1,374 | 改一行程式,讓「想一想:」分開播放 | 否 |
| 同上,但題目本身也沒有音檔 | 818 | 題目錄好後自動解決 | 併入下列 |
| 閱讀模式依逗號切段,片段沒有錄 | 180 | 補錄,或改成整句播放 | 視做法 |
| 含數字的句子(填空、數列、算式) | 1,561 | 補錄 | 是 |
| 含英文字母的句子(角 B、AB、f(x)、度 C) | 551 | 補錄 | 是 |
| 其他(比較符號、括號等) | 305 | 補錄 | 是 |
| 想一想題目被切成兩段以上 | 約 440 | 視情況補錄 | 部分 |

估計:約 1,700 個片段不用錄音就能解決;**需要補錄的約 2,900 到 3,300 個片段,約 5 到 6 萬字**。

完整清單:[繁體版缺音檔清單_20261113.txt](繁體版缺音檔清單_20261113.txt)。清單裡的文字是頁面前處理後的樣子(例如「=」已變成「等於」)。

## 限制

- 這是程式比對,不是試聽;已有音檔的句子,讀音是否正確不在這次掃描範圍。
- 掃描中途我另外執行過一次查詢,可能讓個別一兩句的結果不準,不影響整體數字。

## 修正結果(2026-11-13)

使用者指示「全部修正」後做了三件事,`預錄` 和 `交付_課程音檔` 兩份同步:

1. **補索引對應 2,157 筆**。把既有音檔的鍵依頁面的前處理規則再算一次(例如「2 個」→「兩 個」、「=」→「等於」),讓前處理後的文字也找得到原本的音檔。沒有新增音檔。
2. **修改頁面播放程式 2 處**:
   - 「想一想:」加入可分開播放的開頭語清單。
   - 閱讀「全部朗讀」的中文不再依逗號切段,改為整段交給播放程式,由它依句號切句。
3. **補錄 2,408 句**(Azure,zh-TW-HsiaoChenNeural,整句,已去靜音)。另有 1 個只有引號「」」的片段,對應到 0.15 秒靜音檔。

修正後索引 93,818 筆。

**讀音處理**(完整對照見 [補錄紀錄_20261113.txt](補錄紀錄_20261113.txt)):
- 符號:`>` 大於、`<` 小於、`○` 圈圈、`□` 方格、`//` 平行、`~` 相似於、`a : b` 比、`10⁶` 10 的 6 次方、`a₁` a 1、`|−7|` 負 7 的絕對值、`60–70` 60 到 70。
- 括號:不讀,用停頓;`)(` 之間和「數字或字母緊接括號」補上「乘」;`f(x)` 讀 f x。
- 英文字母:逐一用字母讀音;`cm`、`mL`、`L` 接在數字後讀公分、毫升、公升。
- 多音字:沿用先前的單字與詞語覆寫規則;「數」分動詞(ㄕㄨˇ)與名詞(ㄕㄨˋ),另加「重根」ㄔㄨㄥˊ、「轉半圈」ㄓㄨㄢˋ、「量角器/量長」ㄌㄧㄤˊ、「得 負1」ㄉㄜˊ。
